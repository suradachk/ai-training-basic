# 🤖 AI & AI CLI (Antigravity) Workshop — ฉบับ 2 ชั่วโมง

Web Dashboard และสื่อการสอน **AI + AI CLI (Antigravity)** สำหรับสอนคนในครอบครัว น้องๆ มัธยม นักศึกษา และบุคคลทั่วไป  
สไตล์ **Minimal Dark Mode** คมชัด อ่านง่าย สบายตา ไม่ฉูดฉาด

---

## 🌐 Routes หน้าจอการใช้งาน

1. **หน้าแรก (Role Picker):** `http://localhost:3000/#/`  
   - หน้าหลักสำหรับเลือกเข้าใช้งานระหว่าง **โหมดคนสอน** หรือ **โหมดนักเรียน**
2. **👨‍🏫 โหมดคนสอน (Teacher Hub):** `http://localhost:3000/#/teacher`  
   - **สไลด์สอนสด (Slide Mode):** สไลด์ฉายจอขนาดใหญ่ รองรับการกดลูกศรคีย์บอร์ดซ้าย/ขวา และ Spacebar
   - **บทพูดเปิดคลาส (Icebreaking Script):** สคริปต์พูด 3 นาทีสร้างบรรยากาศเป็นกันเอง
   - **แผนการสอน 5 หัวข้อ:** พร้อมไทม์ไลน์ 2 ชม. และตัวอย่างเปรียบเทียบ
   - **คู่มือติวเตอร์ & Checklist:** สรุปวิธีคุมเวลาและวิธีแก้ปัญหาเฉพาะหน้า
3. **🎓 โหมดนักเรียน (Student Hub):** `http://localhost:3000/#/student`  
   - **สรุปเนื้อหาบทเรียน:** 5 หัวข้อพร้อมตัวอย่างจริง
   - **เครื่องมือสร้าง Prompt (RTCF Playground):** กรอก 4 ช่องแล้วก๊อปปี้ไปส่ง AI ได้ทันที
   - **คลัง Prompt สำเร็จรูป:** ก๊อปปี้ 1 คลิก
   - **โจทย์ Mini Project 15 นาที:** พร้อม Prompt เริ่มต้นสร้างเว็บ
   - **สูตรแก้ Error (F12 Cheat Sheet):** 3 สเต็ปแก้บั๊ก

---

## 🚀 วิธีเปิดใช้งาน

เปิด Terminal แล้วพิมพ์:
```bash
npm run dev
```
ระบบจะเปิดหน้าเว็บขึ้นมาที่ `http://localhost:3000` โดยอัตโนมัติ
