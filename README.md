# 🤖 AI & AI CLI (Antigravity) Workshop — ฉบับ 2 ชั่วโมง

Web Dashboard และสื่อการสอน **AI + AI CLI (Antigravity)** สำหรับสอนคนในครอบครัว น้องๆ มัธยม นักศึกษา และบุคคลทั่วไป  
สไตล์ **Minimal Dark Mode** คมชัด อ่านง่าย สบายตา ไม่ฉูดฉาด

---

## 🌐 Routes & ฟีเจอร์เด่น

1. **หน้าแรก (Role Picker):** `http://localhost:3000/#/`  
   - หน้าหลักสำหรับเลือกเข้าใช้งานระหว่าง **โหมดคนสอน** หรือ **โหมดนักเรียน**
2. **🏠 คลังความรู้ AI ในครอบครัว & ชีวิตจริง:**
   - 💊 แปลผลตรวจสุขภาพ / จัดเมนูอาหารโรคประจำตัว / เช็กข้อควรระวังยา
   - 🛡️ ตรวจเช็กข่าวปลอมใน LINE / ป้องกัน SMS & แก๊งคอลเซ็นเตอร์หลอกลวง
   - 👨‍👩‍👧 วางแผนทริปครอบครัว 3 รุ่น / เมนูอาหาร 7 วัน + Grocery List / DIY งานบ้าน
   - 🎓 ติวการบ้านลูกแบบ Socratic / แต่งนิทานก่อนนอนเฉพาะตัว / ซ้อมคุยภาษาอังกฤษ
   - 💰 เปรียบเทียบเครื่องใช้ไฟฟ้าก่อนซื้อ / วางแผนการเงิน 50-30-20
   - ❤️ การสื่อสารเชิงบวก (NVC) / กิจกรรมกระชับความสัมพันธ์ในบ้าน
3. **👨‍🏫 โหมดคนสอน (Teacher Hub):** `http://localhost:3000/#/teacher`  
   - **สไลด์สอนสด (Slide Mode):** สไลด์ฉายจอขนาดใหญ่ รองรับการกดลูกศรคีย์บอร์ดซ้าย/ขวา และ Spacebar
   - **คลังความรู้ AI ในครอบครัว:** สาธิต Use Case จริงในชีวิตประจำวัน
   - **บทพูดเปิดคลาส (Icebreaking Script):** สคริปต์พูด 3 นาทีสร้างบรรยากาศเป็นกันเอง
   - **แผนการสอน 5 หัวข้อ & คู่มือติวเตอร์:** สรุปวิธีคุมเวลาและเช็กลิสต์
4. **🎓 โหมดนักเรียน (Student Hub):** `http://localhost:3000/#/student`  
   - **คลัง Prompt ครอบครัวพร้อมใช้:** ก๊อปปี้ 1 คลิก นำไปใช้งานได้ทันที
   - **เครื่องมือสร้าง Prompt (RTCF Playground):** สั่งงานเป๊ะ 4 ช่อง
   - **โจทย์ Mini Project 15 นาที & สูตรแก้ Error (F12 Cheat Sheet)**

---

## 🚀 วิธีเปิดใช้งาน

เปิด Terminal แล้วพิมพ์:
```bash
npm run dev
```
ระบบจะเปิดหน้าเว็บขึ้นมาที่ `http://localhost:3000` โดยอัตโนมัติ
